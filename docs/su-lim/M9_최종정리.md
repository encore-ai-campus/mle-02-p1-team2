# M9 최종 정리 (송수림)

산업재해 단위 프로젝트 · SIF 사고사례 RAG · 작성 10/04

## 1. 한눈에 보기

6,032건의 산업재해 사고사례를 근거로 질문에 답하는 RAG 챗봇과, 같은 데이터를 보여주는 분석 대시보드를 만들었다.

```
원본 6개 → 전처리(M2) → 분석(M3) → 문서 임베딩 + ChromaDB(M4)
        → RAG 체인(M5) → 골든 셋 평가(M6) → 개선 실험(M7) → Streamlit 앱(M8)
```

| 단계 | 핵심 결과 | 위치 |
|---|---|---|
| M2 | 사고사례 6,032건 확정, 결측·이상치·중복 기준 문서화 | `docs/su-lim/M2_전처리_명세서.md` |
| M3 | 제조업은 분산(상위 28.3%), 건설업은 소수 기인물 집중(상위 8개 36.6%) | `notebooks/su-lim/03_*.ipynb` |
| M4 | text-embedding-3-small, ChromaDB 6,032건 적재 | `04_*.ipynb` |
| M5 | 유사도 0.40 미만이면 거절하는 근거 기반 답변 | `05_*.ipynb` |
| M6 | 골든 100문항 평가: 정확 검색 기준 사례 Hit@5 0.869, 현장 말투 0.26 | `06_*.ipynb`, `golden_set_100.csv` |
| M7 | 통계 문서를 규모×연도 220건으로 분리해 통계 질문 개선 | `07_*.ipynb` |
| M8 | 필터 공통 적용 대시보드 + 챗봇 | `app/su-lim/08_app.py` |

## 2. 실행 방법

사전 조건: `data/processed`, `data/analysis`, `data/chroma`가 있어야 한다(데이터는 레포에 올리지 않는다). `.env`에 `OPENAI_API_KEY`를 넣는다.

```bash
cd unit1_project
source .venv/bin/activate
uv pip install streamlit altair
streamlit run app/08_app.py
```

- 대시보드는 `.env`가 없어도 동작한다. 챗봇만 키가 필요하다.
- 프로젝트 폴더가 다른 곳이면 `APP_ROOT=<폴더>` 환경변수로 지정한다.
- 처음 실행 때 나오는 이메일 입력은 비워 두고 엔터를 누른다.

## 3. 시연 순서 (3분)

1. **대시보드**: 지표 4개와 차트 4개를 보여 준다. 업종을 `건설업`으로 바꿔 숫자가 변하는 것을 보여 준다.
2. **챗봇 (근거 있음)**: 업종 `전체`로 두고 "컨베이어에 끼인 사고는 어떻게 예방하나요?" → 원인·대책·출처 카드.
3. **챗봇 (필터)**: 업종 `건설업` + 연도 2015~2020으로 "비계에서 추락한 사고를 예방하려면?" → 출처가 모두 범위 안인지 확인.
4. **챗봇 (근거 없음)**: "오늘 서울 날씨 알려줘" → "제공된 사례에서 근거를 찾을 수 없습니다." (환각 방지)
5. **통계 질문**: 업종 `전체`로 "2025년 5인 ~ 9인 사업장 사고사망자수는?" → 통계 자료 출처.

## 4. 한계

- 현장 말투 질문의 검색 성능이 낮다(Hit@5 0.26). 질문이 짧고 일반적일수록 유사도가 낮아 근거 없음으로 처리될 수 있다.
- 통계는 규모별 사고사망자수 한 가지뿐이다. 통계 문서의 업종구분이 `통계`라서 업종 필터가 걸리면 검색되지 않는다.
- ChromaDB의 근사 검색은 컬렉션을 새로 만들 때마다 순위가 조금씩 달라진다. 비교 평가는 전수 코사인 검색 기준으로도 확인했다.
- 골든 셋의 정답 라벨은 보조 판정이고 사람이 확정한 값이 아니다. 팀 기준(관련 / 부분관련 / 비관련 / 애매)에 맞는 사람 검토가 남아 있다.
- 원본 데이터 이용 조건은 팀에서 재확인 중이라, 레포에는 원본·가공 데이터를 올리지 않았다.

## 5. KPT

- M단계마다 노트북 하나씩 만들고 결과 숫자를 바로 기록한 것

**Problem (문제)**
- 원본 질문이 사례 문장을 그대로 베낀 것이어서 초기 점수(0.84)가 부풀려졌다
- 컬렉션을 다시 만들 때마다 수치가 흔들려 비교 기준을 정하는 데 시간이 들었다
- 통계 질문은 구조상 업종 필터와 함께 쓸 수 없다

**Try (시도할 것)**

- 팀 기준에 맞춘 골든 셋 v2(③ 유사 사고사례, ④ 사고원인·재발방지)를 만들어 같은 평가로 비교하기
