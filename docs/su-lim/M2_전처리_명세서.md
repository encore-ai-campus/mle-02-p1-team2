## 2. 처리 기준과 이유

| 항목 | 기준 | 이유 |
|---|---|---|
| 결측치 | 삭제·대체하지 않고 NaN 유지 | 임의 대체는 통계를 왜곡한다. 팀 합의(⑤번 결측은 NaN 유지)와 동일 |
| ⑤번 결측 14개 | NaN 유지. 14개 모두 ④번 사업장수가 0인 칸 | 해당 규모의 사업장이 없어 사망만인율을 계산할 수 없는 값이다. 0으로 채우면 "사망자 없는 안전한 업종"으로 오해된다 |
| `분류 불가`(기인물) | 원본 `기인물`은 보존하고 `기인물_표준`에서만 NaN 처리(제조업 398건, 15.5%) | 원본 보존과 분석·필터링 편의를 함께 확보 |
| 이상치 | 삭제·변환하지 않고 IQR 후보 수만 기록(2번 45, 3번 18, 4번 37, 5번 35) | 후보는 규모 컬럼마다 고르게 분포하고 업종 간 규모 편차에서 비롯된다 |
| 사망만인율 극단값 | 삭제하지 않는다. 석탄광업및채석업이 8개(50-99인 8,333.33, 5인미만 4,444.44 등)로 가장 많다. 분석·시각화에서 별도 표기한다 | 극소수 모집단에서 사망 1건이 비율을 크게 키우는 구조의 값으로 보이며, 해당 칸의 분모는 별도 확인이 필요하다 |
| 중복 | 전체 행 중복 0건. `재해개요`가 동일한 건설업 1쌍은 삭제하지 않고 `재해개요중복` 표시 | 같은 문장이 별개 사례일 가능성을 배제할 수 없다 |
| 재해연도 | `재해개요`에서 추출한 `재해연도` 컬럼 추가. 원문 오타(`2023월` 등 5건)와 날짜형(`2020.10.24.` 1건)은 앞 4자리로 보정(제조업 2건, 건설업 4건). `재해개요` 원문은 수정하지 않는다 | 연도별 분석과 필터링에 사용 |
| 텍스트 | 연속 공백·nbsp 정리, 줄바꿈 유지 | 의미 훼손 없이 검색·임베딩 품질 확보 |
| 업종명 | 공백 제거, `전기가스증기수도사업` → `전기·가스·증기·수도사업`, 건설업 시트는 `산재업종(중분류)`를 `건설업`으로 지정 | ①중분류와 ②~⑤ `구분`을 같은 키로 조인하기 위함 |
| 규모명 | `5인미만`, `5-9인`, … , `1000인이상`으로 통일(③의 `10인 ~ 19인` 등 포함) | ②~⑤ 간 표기 차이 해소 |

## 3. 추가된 컬럼(1번)

`업종구분`, `기인물_표준`, `재해연도`, `재해개요중복`, (건설업) `산재업종(중분류)`

## 4. 알려진 한계와 후속 작업

- 제조업 `기인물`의 종류가 626개로 많아 RAG 메타 필터로 쓰려면 묶기(M4 설계)가 필요하다.
- 건설업 `재해유발요인`은 3,300종으로 거의 자유서술이다. 필터 기준으로는 `기인물`(57종)과 `재해종류`가 현실적이다.
- 사망만인율 극단값의 분모(근로자수)는 현재 파일로 검증하지 못했다. 시각화(M3) 시 로그 스케일 또는 해당 업종 제외 버전을 함께 제시한다.
- 재현 방법: raw는 수정하지 않았고, 노트북 셀을 위에서부터 실행하면 processed가 같은 결과로 다시 생성된다.
