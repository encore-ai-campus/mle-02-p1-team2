## 지금 적용할 기준

- ‘다운로드할 수 있음’, ‘API 호출 승인을 받음’, ‘RAG에 문서를 복사·변환해 넣어도 됨’은 서로 다른 조건이다.
- ②~⑤와 ⑦은 공공데이터포털에 표시된 범위 안에서 분석·시각화에 사용한다. API 신청·인증키는 호출 권한이므로 라이선스와 따로 관리한다.
- ①은 원본 파일을 수정하지 않는다. 수업용 프로젝트에서 전처리본·청크·임베딩을 외부 API에 사용한 상태이며, 외부 공개·재배포는 하지 않는다.
- ⑥의 자료 목록 라이선스를 연결 PDF에 확대 적용하지 않는다. 실제 보고서 PDF는 현재 수업 범위에서만 다루고 외부 공개·재배포하지 않는다.
- ⑧은 수업 안에서만 사용한다. 개별 GUIDE 이용조건이 확인되지 않았으므로 공개 저장소나 공개 앱에는 원문·청크를 올리지 않는다.
- ①·⑥·⑧ 자료는 개인 프로젝트의 벡터 DB에 적재해 검색 테스트했다. 임베딩에는 OpenAI text-embedding-3-small API를 사용했고, 답변 생성 시 검색된 문서 조각도 OpenAI API로 전달될 수 있다. 이는 이용허락을 확인했다는 뜻이 아니다. 2026-10-03 공개 Streamlit 배포 요청이 들어왔으나, 권리 범위와 공개 시 API 사용량 보호를 확인하기 전까지 생성은 보류한다.

## 이번에 알게 된 점

포털의 데이터 목록과 그 안에서 내려받는 파일은 라이선스가 다를 수 있다. 그래서 ⑥은 목록의 5행 CSV와 사고조사보고서 PDF를 따로 봐야 했다. KOSHA GUIDE도 공식 사이트에서 받은 파일이라는 이유만으로 재사용 조건이 정해지는 건 아니어서, 파일별 허용 범위를 확인해야 한다.

## 공개 범위가 바뀌면

문의 초안은 [`data_usage_inquiry_draft.md`](data_usage_inquiry_draft.md)에 참고용으로 작성해 두었다. Streamlit 공개 배포 요청으로 외부 공개 검토가 시작됐지만, 이 초안을 기관에 보내지는 않았다. 공개 이용 승인 또는 강의 담당자의 사용 범위 확인이 있기 전까지 앱을 만들지 않는다.

## 이번에 추가로 확인한 점과 유의사항

- Streamlit 배포 화면은 GitHub 저장소 앱을 공개 앱으로 만든다고 표시한다. 링크만 팀 안에 공유하더라도 접근이 제한된다고 볼 수 없다.
- 공개 RAG는 검색된 자료 일부를 앱 화면에 표시하고, 방문자 요청마다 OpenAI 검색·답변 호출이 발생할 수 있다. 자료 권리와 사용량 제한을 함께 확인해야 한다.
- 공개 권한이 확인되기 전까지 개인 Fork의 앱 코드 수정·테스트까지만 진행하고, Cloud 앱 생성과 키 입력은 하지 않는다.
