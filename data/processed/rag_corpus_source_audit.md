# RAG 근거 코퍼스 출처·이용조건 점검

- 확인일: 2026-10-02
- 목적: RAG 색인 후보를 출처별로 구분하고, 원문 수집 전에 필요한 이용조건 확인사항을 기록
- 범위: 공개 페이지와 메타데이터 확인. API 호출과 원문 파일 다운로드는 하지 않음.

## 판정 기준

사례 본문을 복제·정제·분할·임베딩해 검색에 사용하는 단계는 원문에 대한 변형 또는 2차 이용이 수반될 수 있다. 따라서 출처 페이지의 공개 여부만으로 색인 허용을 추정하지 않는다. 해당 파일에 표시된 이용허락 범위 또는 제공기관의 명시적 허가를 확인한 뒤 수집한다.

## 출처별 점검 결과

| 후보 | 확인된 자료 형태 | 확인된 이용조건 | RAG 색인 상태 |
|---|---|---|---|
| SIF 아카이브 XLSX (15140383) | 무료 다운로드 XLSX. 공단 설명상 2016~2023년 사례를 수록. | 공공누리 제3유형(출처표시·변경금지); 자료 페이지가 변경·2차적 저작물 작성을 금지한다고 명시. 수정일 2026-09-30. | **HOLD** — 텍스트 추출·정규화·청킹·임베딩이 변경금지에 해당하는지 공식 페이지에서 해소되지 않음. 제공기관 허가 전 인제스트하지 않음. |
| SIF 아카이브 조회 OpenAPI (15161362) | 무료 REST/JSON 서비스. | 이용허락범위 제한 없음. 개발계정 자동승인, 신청 가능 트래픽 1,000(기간 단위 미표기); 운영계정 심의승인 및 활용사례 등록 후 증량 신청. 수정일 2026-09-21. | **개발 경로 사용 가능** — API 조건·트래픽을 지키고 출처를 표시하는 로컬 프로토타입 기준. 운영계정 심의 전 운영 배포 불가. 정적 XLSX에는 적용되지 않음. |

| AI친화 학습데이터 (15162988) | 5행짜리 공개자료 URL·설명 목록 | 공공누리 제3유형. 페이지가 원문 보고서 PDF와 중대재해사이렌은 각각 법령·이용조건을 확인하라고 명시 | **목록 전용** — 사고 본문 코퍼스로 사용하지 않음 |
| 고용노동부 재해조사보고서 | 게시판에서 보고서 메타데이터와 PDF 첨부 확인. 확인 시 게시판 전체 51건 | 부처 정책은 부처가 저작권 전부를 가진 자료 중 공공누리 제1유형 표시 자료의 자유 이용을 안내. 표시가 없는 자료는 사전 협의, 제3자 저작물은 단순 열람 외 복제·변경·배포 제한 | **HOLD** — 개별 PDF의 공공누리 표시·권리자를 확인하고 필요 시 사전 협의 |
| 산업안전포털 업무상 사고사례 | 업종별 사례 페이지와 PDF 첨부·전체 다운로드 제공 확인 | 확인한 사례 페이지에서 개별 첨부파일의 재사용 라이선스 표시를 확인하지 못함 | **HOLD** — 문서별 이용표시 또는 공단 허가 확인 |
| 중대재해 사이렌 | 산업안전포털 공개 경로 확인 | AI친화 학습데이터 안내는 별도 이용조건 확인을 요구함 | **HOLD** — 배포 문서별 이용조건 확인 |

OpenAPI 표본은 2026-09-28에 10개 검색어로 수집한 1,048건이며 전체 아카이브가 아닙니다. API 품질 점검에서 `disasterType`은 전부 결측이고 `cateSeNm`은 단일 값 `전업종`이었습니다. 이 두 필드는 필터로 사용하지 않으며, 세부 업종은 값이 있는 `sifLclsfNm`·`sifMclsfNm`·`sifSclsfNm`로 다룹니다. 자세한 결측률과 수집 검색어별 첫 발견 수는 [API 코퍼스 프로파일](sif_api_corpus_profile.md)을 참고합니다.

## 권고 수집 경로

1. 정적 SIF XLSX는 변경금지 조건에 따라 HOLD한다. SIF OpenAPI는 별도 서비스 경로이므로, 표시된 이용범위와 계정·트래픽 조건을 지켜 로컬 프로토타입에 사용한다.
2. 이용표시가 없거나 변경금지인 자료는 제공기관에 내부 교육용 텍스트 추출, 청킹, 임베딩, 로컬 벡터 저장, 시연 범위별 허용 여부를 문의한다.
3. 승인된 문서만 로컬 원본으로 보관하고, 문서 ID·제목·원 URL·게시일·권리표시·확인일을 manifest에 기록한다.
4. 허용된 코퍼스가 확보되면 페이지 단위 추출·청킹·출처 표시를 적용하고, 원문·임베딩의 공개 저장소 업로드는 별도 허가가 없는 한 제외한다.

제공기관에 전달할 문의 문안은 [이용범위 확인 초안](rag_corpus_permission_request.md)에 작성했다. 초안은 발송하지 않았다.
