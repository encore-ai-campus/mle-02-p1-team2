# 산업재해 RAG 원문 이용범위 확인 문안

- 상태: 초안 — 발송하지 않음
- 대상 후보: SIF 아카이브, 재해조사보고서, 산업안전포털 업무상 사고사례·중대재해 사이렌
- 프로젝트: 비상업적 교육·개인 프로젝트의 로컬 RAG 실험

## 문의 제목

산업재해 공개자료의 로컬 RAG 실험 이용범위 문의

## 문의 내용

안녕하세요.

산업재해 예방을 위한 교육·개인 프로젝트로 공개 사고사례를 검색하고, 유사 사례의 원인과 예방대책을 출처와 함께 제시하는 RAG 시제품을 준비하고 있습니다.

아래 자료의 이용조건을 확인하고자 합니다.

- 자료명/게시물명: [자료명과 게시물 URL 기입]
- 제공기관: [한국산업안전보건공단 또는 고용노동부]
- 프로젝트 목적: 비상업적 교육·개인 프로젝트 시연

다음 작업이 허용되는지 자료별로 안내 부탁드립니다.

1. 원문 PDF의 텍스트를 로컬에서 추출하고 검색에 필요한 범위로 정리하는 작업
2. 문서를 사례 단위 또는 페이지 단위로 나누는 청킹 작업
3. 임베딩 벡터를 생성해 개발자 개인 PC의 PostgreSQL/pgvector에 저장하는 작업
4. 시제품 화면에서 짧은 근거 발췌문, 문서명, 원문 링크를 표시하는 작업
5. GitHub 저장소에 코드와 스키마만 공개하고 원문·추출 텍스트·임베딩은 공개하지 않는 방식

추가로 다음 사항도 알려주시면 감사하겠습니다.

- 자료별 적용되는 이용허락 표시와 저작권자/제3자 권리 포함 여부
- 내부 실험 및 발표 시연에 필요한 출처표시 문구
- 원문 또는 벡터 데이터의 보관기간·삭제 조건
- 위 사용범위 중 허가가 필요한 경우의 신청 절차와 담당 부서

허가 범위가 확인되기 전에는 원문을 정제·청킹·임베딩하거나 벡터 저장소에 적재하지 않겠습니다. 회신 내용을 자료별 manifest에 기록하고 허용된 범위 안에서만 사용하겠습니다.

감사합니다.

## 발송 전 기입·확인 항목

- [ ] 수신 기관과 담당 부서/담당자 확인
- [ ] 요청할 개별 문서 URL과 파일명 기입
- [ ] 발표자료·시연 공개 범위 기입
- [ ] 회신의 허용 범위·출처표시·보관 조건을 문서로 보관
